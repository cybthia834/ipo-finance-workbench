| 模块 | 实际变化 |
| --- | --- |
| 主题与外壳 | 新增 `theme/tokens.ts`、`theme/base.css`，统一共享样式；更新登录、首页、清单、详情等页面外观；加入手机抽屉导航与跳到正文入口 |
| 请求与会话 | 请求增加取消、超时和基础响应结构校验，保留 `as_of/trace_id`；仅 401 视为认证失效，`/me` 服务失败有单独重试界面；登出取消请求并清理本应用 CSRF 与幂等缓存 |
| 写入反馈 | 同步锁防止同一动作连续提交；网络断开和超时提示结果未确认；同页相同请求保留原幂等键，不自动重新 POST |
| 清单契约 | 为列表、预检、任务、分派结果及首页补充类型；清单和任务增加运行时边界校验；未将历史页面所有 `any` 清零 |
| 筛选与导航 | 清单仅发送白名单查询字段；支持期间、快捷筛选、保存及应用本人视图；详情标签页刷新恢复，切换标签后返回仍保留列表条件 |
| 清单生成 | 预检后创建真实任务，任务 ID 放入 URL；刷新后查询同一任务；按真实状态轮询，网络失败退避、隐藏页面暂停，离开组件取消查询；可停止等待或关闭面板 |
| 首页 | 显示数据截至时间，支持主体与期间筛选；下钻带对应范围；不在前端重新计算业务统计 |
| 报表与导出 | 快照、审批、效率请求分别呈现错误；展示导出任务排队、执行、重试与失败状态；有活动任务时更新查询；下载统一处理错误，文件过期禁用入口 |
| 目录与弹窗 | 目录表在窄屏局部横滚；表单改为单列，提交按钮可在弹窗内滚动到达；Escape 关闭后焦点返回入口 |

生成任务的“停止等待”只停止浏览器查询，不取消后台任务。已获得任务 ID 的刷新恢复和未获得 ID 的跨刷新操作核对是两种能力，后者仍未完成。

## 本轮接口变化

接口前缀为 `/api/v1`。最新路由快照已同步至 [OpenAPI](../openapi.json)；输出 schema 仍有一期遗留缺口，不能将该文件视为完整的自动生成客户端依据。

| 接口 | 变化与约束 |
| --- | --- |
| `GET /projects/{id}/issues` | 增加可选 `period_id`；按整改关联的缺口及清单期间过滤，与看板相同；无该期间关联的独立整改不进入期间统计 |
| `GET /projects/{id}/approvals` | 在原审批对象授权通过后，返回对应导出任务的安全摘要 `job`，含 `id/state/attempts/error_code/next_run_at`；不暴露执行 token、任务原始 payload 或文件路径 |
| `POST /me/views` | 纳入统一幂等命令；需与其他写接口一致携带 `Idempotency-Key`；相同键及正文返回原记录，改正文复用键返回冲突 |
| `POST /projects/{id}/metric-samples` | 同样纳入统一幂等命令；保留原有授权和字段校验 |

`GET /jobs/{id}` 的本人任务访问规则没有放宽。审批有权人只能通过审批接口看到对应安全摘要，并不因此获得他人的完整任务记录。接口变更未新增数据库表或迁移。

环境为 macOS arm64、Node.js 24.18.0、Python 3.14.7、Google Chrome 154.0.8037.98；使用独立无头 Chrome、真实 FastAPI、worker 和 PostgreSQL。浏览器操作使用开发库，后端夹具仅使用独立 `finance_phase1_test` 测试库，未操作旧 55432 数据库。

| 检查 | 结果 |
| --- | --- |
| `npm run lint` | 通过 |
| `npm run typecheck` | 通过 |
| `npm run test:unit` | 5 项通过，覆盖 URL 白名单、失效范围、空与异常响应、任务结构及状态 |

| `npm run test:e2e` | 16 项全部通过，耗时约 54.3 秒，包含本轮新增 10 项及原有 6 项 |

新增浏览器检查覆盖四个尺寸的首页、清单、详情、目录弹窗，以及整改、报表、设置和审计入口；检查页面无异常横滚、窄屏表格可以横滚、弹窗提交按钮可达、Escape 与焦点返回、没有页面脚本异常。尺寸为 1440×1050、1280×800、768×1024、390×844。

可保存的结果摘要见 [validation.json](validation.json)。本机原始浏览器报告为 `.runtime/e2e-results.json`，后端报告为 `.runtime/frontend-phase2/backend-results.xml`；未修改一期验证产物。

交互用例覆盖筛选返回与个人视图、生成确认防连点、任务刷新恢复、会话服务异常、非 JSON 网关错误、报表局部失败及期间整改下钻。另通过真实 `route.fetch()` 提交生成任务后丢弃浏览器响应，验证同页再次确认沿用原幂等键并取得同一任务 ID。故障用例使用网络拦截，其写入与恢复结果仍来自真实后端。

原有回归继续验证经办登记、独立复核、换版重核、历史保留、快照、设置及 IT 账号入口。换版用例已改为支持已有历史复核次数，不再只能在首次演示状态下运行。浏览器测试会追加虚构目录、快照及个人视图，未将演示数据重置。

测试修复过的实际问题包括详情标签页导致返回筛选丢失、窄屏目录列挤压、按钮图标影响可访问名称。截图等待业务内容和弹窗动画完成，避免将旧页或加载中截图当成结果。初次沙箱禁止 Chrome 启动的情况已通过获准运行复测，与业务断言失败分别处理。

## 运行与回退

按根目录 [README](../../README.md) 启动独立数据库与 `npm run dev`，页面地址为 `http://127.0.0.1:5173`。随机演示密码只在本机 `.runtime/phase1/demo-credentials.json`，不复制到文档或截图。

如需比较一期界面，应先保存当前工作，再使用一期分支或独立检出。不要直接重置当前工作区、覆盖未提交文件或删除演示库。当前后端联动以新增字段、可选筛选和统一幂等为主，回退部署仍需核对前端与 API 版本匹配。
