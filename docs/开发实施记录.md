# 第一阶段开发实施记录

2026-10-08 开始开发。已完整通读根目录《技术适配声明》V0.2 与《第一阶段技术开发文档》V0.2。原需求文档与技术栈手册保留。

## 工作基线

工作区起初仅有需求和设计文档，Git 中有历史实现。本轮仅恢复缺失源码、配置与测试，不覆盖当前设计文档，不恢复历史验证报告。历史代码作为待验证基线，不视为本轮验收结果。

发现旧 PostgreSQL 运行于废纸篓目录、端口 55432。本轮独立环境为 `.runtime/phase1`、端口 55434、数据库 `finance_phase1_dev` 与 `finance_phase1_test`。不连接或修改旧数据。恢复演练使用 55435。

## 实施顺序

1. 独立 PostgreSQL、依赖、迁移和现有流程基线测试。
2. 权限并发边界、账号管理、任务租约与失败恢复。
3. 模板实例升级、复核来源和整改历史约束。
4. XLSX 与清单导出、过期清理、查询与界面补齐。
5. 集成、浏览器与恢复验证，更新操作说明及实际完成情况。

内网正式部署、真实字段准入、人员签字及真实节时数据另需组织环境。开发验证仅使用虚构数据。

## 本轮实际交付

开发方式按文档的纵向切片执行，核心出口是经办登记目录、另一人独立复核、目录换版后扣回有效完成并保留旧结论。当前已在真实 PostgreSQL 与真实浏览器中跑通该链路，并补齐相关管理和可靠性功能。下表只记录已存在的实现。

| 实施项 | 实际实现 |
| --- | --- |
| 开发起点 | 从 `c9680d8` 复制 59 个缺失源码、配置及测试文件；不覆盖本轮设计文档，不恢复历史测试结论 |
| 环境 | 固定锁文件，创建 `.venv`；独立 PostgreSQL 18.4，开发、测试及恢复互相隔离 |
| 数据迁移 | 保留 0001/0002 历史迁移，新增 0003 账号版本、0004 任务租约及导出保留、0005 复核来源和模板采用历史 |
| 身份与会话 | 新增账号管理真实页面，创建/停用/启用/重置密码，首次改密，10 个活动账号上限，身份变更撤销全部会话 |
| 初始业务授权 | 新建项目必须选择财务负责人；IT 创建项目不会自动取得该项目 CFO 权限；项目人员授权可以选择尚未加入的活动账号 |
| 权限并发 | 先身份锁，再项目锁；正常业务持有身份共享锁，身份变更持有排他锁；项目读共享、写排他。停用等待已经授权的事务结束，新请求重新鉴权 |
| 业务基线 | 保留范围、33 项候选模板、分派、三值适用性、目录准入、版本、独立复核、缺口、整改、延期、重开、看板及快照功能 |
| 历史保护 | 目录、提交、复核、缺口、行动、快照及审计不可改写；新增缺口固定来源引用、受限核查方式与核查时间 |
| 模板实例评估 | 清单详情展示新版标准，可以采用或保留并记录原因；采用后需要重新复核，原提交仍引用原标准，决策表由数据库保护为只追加 |
| 大列表 | 清单、目录、整改、审计均使用数据库权限筛选、COUNT、OFFSET/LIMIT 与稳定次序；目录候选支持服务端搜索 |
| 任务 | 领取记录单独提交，60 秒租约、20 秒心跳；最多 3 次执行，5/15 秒退避；比较执行 token 后才提交业务结果，过期旧执行不能覆盖新结果 |
| 导出 | ZIP 包中包含 XLSX、原始快照 manifest 与校验清单；工作簿包含说明、清单、整改、目录版本四个工作表；文字强制使用字符串类型 |
| 导出权限与清理 | 生成前及发布前重新检查授权，下载在事务内读取并校验文件；过期副本与孤儿文件可重复清理，保留有效执行使用中的临时文件 |
| 页面重试 | 网络结果不确定时在当前页面会话保留同一幂等键；退出账号清理请求缓存。不同账号/项目的页面数据重新加载 |
| 交付材料 | 新 README、按当前代码生成的 OpenAPI、实际验证报告和当前页面截图 |

XLSX 的 `metadata_hash` 表示目录元数据摘要，未计算或声称持有原件哈希。普通接受与受限已核继续分列。所有开发、容量、浏览器及恢复样本均为虚构数据。

| 差异检查 | `git diff --check` 通过 | 未提交 Git，也未覆盖用户的其他删除项 |

恢复演练发现旧启动器仅持有原始子进程 PID，无法停止由恢复脚本重启的新实例。已改为按本项目数据目录调用 `pg_ctl`，重新完成启动、恢复、停止验证，退出状态为 0。

开发时遇到的沙箱共享内存、回环连接和 Chrome 启动限制，均在对应命令获得运行权限后重新验证。浏览器初次完整链路检查还发现装饰图标影响按钮的可访问名称，已修正并重跑通过。测试库出现的任务中断模拟按新设计由待重试状态恢复，测试已验证最多三次执行，不再沿用无限等待的旧行为。

当前锁定的 Starlette TestClient 对 `httpx` 发出弃用提示，测试正常通过。后续调整该测试依赖需单独做兼容验证，不在本轮顺带更换。

| --- | --- |
| 范围变更预检 | 已有范围版本和历史保留；尚需补齐变更预检、预检确认以及范围版本并发冲突契约 |

| 引用精细治理 | 复核固定版本和换版重核已实现；尚需显式解除关联、跨期拆分说明、引用级状态及历史引用权限专项检查 |
| 整改完整状态 | 基线有创建、行动、提交验证、关闭、退回、延期、重开；尚需待分派、正式改派、结构化行动完成/阻塞字段和离线核查关联。受限目录暂不能直接作为整改关闭证据 |
